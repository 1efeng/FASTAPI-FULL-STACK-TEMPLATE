# 东京 7 日经典路线

## 行程总览

| 天 | 区域 | 主题 |
| --- | --- | --- |
| D1 | 浅草 / 晴空塔 | 经典地标 + 和服体验 |
| D2 | 上野 / 秋叶原 | 博物馆 + 动漫街区 |
| D3 | 台场 / 东京湾 | 海滨夜景 + 科技馆 |
| D4 | 明治神宫 / 涩谷 | 自然神社 + 都市潮流 |
| D5 | 镰仓一日 | 海岸小城 + 江之电 |
| D6 | 新宿 / 吉祥寺 | 购物 + 杂货探店 |
| D7 | 自由活动 | 补漏 / 伴手礼 |

## 交通建议

- 全程以 JR 山手线 + 地铁为主，推荐购买西瓜卡（Suica），押金可退。
- D5 镰仓建议买「江之电一日券」，随上随下更划算。
- 若住新宿，去机场可乘成田特快（NEX），约 1 小时 20 分钟。

## 预算参考（两人）

- 住宿：中档酒店约 ¥700/晚 × 7 晚 ≈ ¥9800
- 餐饮：每日 ¥300/人 × 14 ≈ ¥8400
- 交通 + 门票：约 ¥2500
- 合计约 ¥2.1 万；预算敏感可换民宿并减少一日远行。

## 实用提示

- 浅草寺清晨人少，建议 8 点前到。
- 台场适合傍晚去，海风 + 夜景 + 高达雕像一起看。
- 春秋两季气候最佳；夏季高温多雨，冬季干燥但室内外温差大。
