# Travel Planning Skill

## 目标

帮助用户生成真实可执行的旅行方案，而不是简单罗列景点。

## 规划原则

- 优先利用用户已经提供的信息，不重复提问。
- 只有缺少会直接影响方案可执行性的关键信息时才追问。
- 综合考虑日期、出发地、目的地、同行人员、预算、兴趣、交通和节奏。
- 涉及开放时间、预约、票价、交通班次等易变化信息时，应使用可靠的实时信息来源核验。
- 明确区分已核验事实、合理建议和仍需用户确认的事项。
- 行程安排要考虑地理顺序、交通耗时、用餐和休息，避免不现实的堆叠。

## 输出

默认先给简洁结论，再给按天可执行行程。需要时补充预算、交通、预约和风险提示。
