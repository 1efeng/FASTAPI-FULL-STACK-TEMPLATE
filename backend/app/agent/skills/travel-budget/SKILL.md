# 旅行预算汇总

本 Skill 只负责指导确定性预算汇总，不负责旅行价格 Research 或方案选择。

使用步骤：

1. 先由 Main 确定最终采用的交通、住宿、餐饮、门票等方案。
2. 每个金额明确使用 ISO 4217 币种代码；不要使用含义不清的裸 `¥`。
3. 只把最终采用方案的项目传给 `calculate_budget`，不要混入备选价格。
4. 固定价格只提供 `amount_min`；区间价格同时提供 `amount_min` 和 `amount_max`。
5. 每人单价设置 `per_person=true`，并提供实际 `people`；住宿晚数等通过 `quantity` 表达。
6. 最终答案引用工具返回的总额、分类金额和人均金额，不要自行重新心算。

`calculate_budget` 不提供城市价格，也不判断哪个方案更好。缺少可靠价格时，应先说明缺口或完成 Research，不能编造精确金额。
