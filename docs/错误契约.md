# Travel Agent v8 错误契约

> 更新时间：2026-08-13  
> 内部异常不直接暴露 C-End。  
> 统一：Internal Failure → Product Error Code → HTTP/SSE → User Message。

# 1. Error Shape

```json
{
  "code": "MODEL_UNAVAILABLE",
  "message": "当前规划服务暂时繁忙，请稍后重试。",
  "retryable": true,
  "request_id": "..."
}
```

# 2. Core Codes

## Request

```text
INVALID_REQUEST
REQUEST_TOO_LARGE
REQUEST_DEADLINE_EXCEEDED
DUPLICATE_REQUEST
REQUEST_CANCELLED
```

## Auth / Abuse

```text
UNAUTHENTICATED
FORBIDDEN_RESOURCE
RATE_LIMITED
QUOTA_EXCEEDED
CONCURRENCY_LIMITED
```

## Agent

```text
AGENT_LOOP_LIMIT_REACHED
MODEL_CALL_LIMIT_REACHED
TOOL_CALL_LIMIT_REACHED
CONTEXT_LIMIT_REACHED
```

## LLM

```text
MODEL_TIMEOUT
MODEL_RATE_LIMITED
MODEL_UNAVAILABLE
```

Application 不需要暴露 LiteLLM 内部 cooldown 状态为独立用户错误。

## Tools

```text
SEARCH_UNAVAILABLE
MAPS_UNAVAILABLE
WEATHER_UNAVAILABLE
FX_UNAVAILABLE
RESEARCH_UNVERIFIED
```

## Data

```text
DATABASE_UNAVAILABLE
STATE_PERSISTENCE_FAILED
CONVERSATION_NOT_FOUND
```

# 3. Partial Degradation

ToolError 不一定升级为 Request Error。

例如：

```text
WEATHER_UNAVAILABLE
→ plan may continue with unverified-weather marker
```

# 4. LiteLLM Mapping

LiteLLM/provider exceptions 由 Gateway adapter 归一到产品模型错误。

不要把 Provider SDK exception class 直接透传 Client。

# 5. Unknown

未知异常：

```text
INTERNAL_ERROR
```

必须记录 request_id / trace_id，用户消息保持通用，不暴露 stack trace。

# 6. Logging

技术错误写：

- request_id；
- trace_id；
- component；
- error type；
- retry/fallback metadata（适用时）。

不写 Secret / unsafe PII。
