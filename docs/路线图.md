# Release Gate

达到最低 10,000 DAU production baseline 前必须：

- P0-1 ~ P0-11 完成；
- 一个正式 Client；
- Basic Eval 通过；
- load test 覆盖预期峰值并保留余量；
- security check 无阻断项；
- backup restore 已验证；
- App / LiteLLM 不依赖单实例关键状态；
- request / trace / cost 可定位；
- critical fact failure 不伪造；
- gray rollback 可执行。
