# 3. Runtime Boundary

```text
TanStack Query
→ REST / durable server state

Chat Runtime（M8 决策：Vercel AI SDK / @ai-sdk/react）
→ active Agent stream

assistant-ui（候选）
→ thread/message/composer UX
```

不要三套状态互相复制。

# 8. Idempotency

用户每次真实发送动作：

```text
new Idempotency-Key
```

网络 retry：

```text
same key
```

Regenerate：

```text
new business request
new key
new request_id
```

# 10. Refresh

先保证：

```text
刷新
→ Business Conversation 可恢复
→ completed final 可读
```

再验证：

```text
running request rejoin/reconnect
```

不要先造复杂 byte-level replay。
