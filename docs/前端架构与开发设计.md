# 6. Refresh / Resume

F5 不等于 cancel。

目标：

```text
Browser reload
→ TanStack Query 拉 durable Conversation/Message
→ ProductChatTransport reconnect
→ backend owned RequestRun check + StreamResumeStore resume
→ 200: current assistant active stream replay + live continuation
→ 204: durable RequestRun/history reconciliation
```

当前已落地的浏览器顺序：

```text
URL conversation_id
→ GET Conversation Detail（durable messages）
→ restore AI SDK UI messages
→ read conversation-scoped active request_id
→ useChat.resumeStream()
→ GET /chat/requests/{request_id}/stream
→ backend 校验 owned RequestRun，并由 StreamResumeStore 判定 200 SSE / 204
```

active request 本地 identity 只用于 conversation-scoped reconnect hint，不成为 Product SOT。浏览器不通过 RequestRun 状态推断 transport 是否存在；GET reconnect 的后端 ownership + StreamResumeStore 结果是唯一判定。收到 204 后再清理本地 active identity，并拉取 RequestRun 与 durable history 完成 UI reconciliation。

第一版优先：

```text
skip_characters = 0
```

即当前 assistant active stream 从头 replay。

不要把 Redis Pub/Sub channel、Redis key、Redis Stream ID 暴露给浏览器。

# 7. Stop

Product Stop：

```text
UI Stop button
→ useProductChat.stopProductRequest()
→ POST /requests/{request_id}/cancel
→ Product Runtime
```

禁止把以下作为 primary Product Stop：

```text
useChat().stop()
AbortController.abort()
关闭 SSE
页面离开
```

AI SDK browser abort 只能是 transport/subscriber 行为。

# 8. Durable Reconciliation

```text

```

```text

```

```text

```
