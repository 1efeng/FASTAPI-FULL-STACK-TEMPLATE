# 3. 两阶段产品架构施工

## Phase A — Generic AI Chat Platform

目标：

```text
用户可以登录
→ 创建会话
→ 连续普通问答
→ 流式接收结果
→ 刷新后恢复
→ 跨实例继续
→ 请求幂等
→ 有 quota / deadline / cancellation
→ 可追踪 / 可评测 / 可部署
```

## Phase B — Travel Domain

基础 Chat Gate 之后：

```text
Travel Skill
Budget
Research Tools
Researcher
Research Trust
Planning / Modification
Travel-specific UI
```

Travel 是上层 Domain Capability，不应该决定底层 Conversation / Streaming / Persistence 架构。

# 7. 为什么 `@langchain/react` 是核心

系统本身是：

```text
Deep Agents
+
LangGraph
```

前端需要理解：

```text
messages
tools
agent state
interrupts
subagents
thread/history
```

因此优先使用 LangGraph-native Frontend Runtime，避免：

```text
LangGraph
→ 翻译成另一套 Chat Protocol
→ 第二套 Runtime
```

```text

```

```text

```

正式接入必须通过 Version/Compatibility Spike。

如果失败：

```text
替换 UI 层
不推翻 @langchain/react / FastAPI / LangGraph
```

# 9. FastAPI Agent Streaming Adapter

它不是第二个 Backend。

职责：

```text

↕
Agent Streaming Protocol
↕
FastAPI Product Lifecycle
↕

```

具体 endpoint 不提前永久锁死，以锁定版本官方 Protocol / Adapter Spike 为准。

# 10. 为什么不直接 Agent Server-first

Agent Server-first 是未来可选架构，不是 P0 默认。

当前保留 FastAPI Product Runtime，因为已经拥有：

```text
Auth / User
Business Modules
PostgreSQL / Alembic
Request Lifecycle
Conversation / RequestRun 设计
Redis / LiteLLM
```

不为了 Streaming 在 P0 推翻 Application Runtime。

未来切换：

```text
必须 ADR
```

# 11. Business Conversation != Agent Thread

```text
Business Conversation
→ Product resource
→ ownership
→ list/history/delete

LangGraph Thread
→ Agent runtime
→ checkpoint
→ resume
```

服务端映射。

客户端 ID 不能成为授权凭据。

# 12. Request Lifecycle

```text
AuthN
→ AuthZ
→ Rate / Quota / Concurrency
→ Idempotency
→ request_id
→ persist user + request_run(running)
→ Agent under E2E deadline
   └→ LangGraph checkpoints
→ LiteLLM / Tools
→ Agent Final
→ persist assistant + request_run(completed)
→ COMMIT
→ stream completion
```

LangGraph checkpoint transaction != business final transaction。

# 17. Streaming

不再把 `status`、`message_delta`、`heartbeat`、`final`、`error` 设计成独立长期自研的 Agent wire protocol。

M8 Streaming Spike 之前，不冻结具体 endpoint 或 wire shape。优先验证当前锁定版本的 LangChain/LangGraph 官方 Agent Streaming Protocol，由 FastAPI Agent Streaming Adapter 接入 Product Lifecycle，再由 `@langchain/react` 消费。

产品化状态可以使用 custom state/channel：

```text
正在查询交通
正在核实信息
正在整理方案
```

不暴露 private Chain of Thought。

# 22. 核心判断

> v7 的长期架构核心不是“旅行工具越多越好”，而是先把一个可持久化、可流式、可恢复、可多实例、可治理的 AI Chat Platform 做稳，再让 Travel Skill / Researcher / Tools 成为它上面的专业能力。
