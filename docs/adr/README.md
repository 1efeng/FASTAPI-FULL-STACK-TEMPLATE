# ADR Index — Post-reset Rules

> Reset date: 2026-08-19

All ADR files created before the 2026-08-19 architecture reset are **Historical ADRs**.

They explain past decisions but do not define the current target architecture.

A pre-reset ADR regains decision authority only when a new post-reset decision explicitly re-adopts it from the current Product and Architecture baselines.

New ADRs must document:

```text
Product requirement
Observed constraint
Options considered
Decision
Rejected alternatives
Validation
Migration impact
```

Current design entry points:

```text
docs/产品文档.md
docs/架构.md
```

Historical material must not be used as a shortcut to avoid re-deriving the new architecture.
