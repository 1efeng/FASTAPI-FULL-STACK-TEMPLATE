# Candidate Plan Design v2

## Definition

Candidate Plan is the intermediate travel hypothesis before verification.

It is not the final answer.

## Lifecycle

Draft
-> Evaluate
-> Research
-> Refine
-> Final

## Schema

{
 strategy,
 experience_goals,
 days,
 strengths,
 risks,
 verification_needed
}

## Principle

Generate plans first.
Research only information that can change decisions.
