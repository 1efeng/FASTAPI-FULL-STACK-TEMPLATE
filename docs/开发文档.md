---

# 8. Business Durability

> 历史：原 M5 LangGraph Persistence（AsyncPostgresSaver / checkpoint）已 SUPERSEDED，v8 不再使用。

v8 的 durability 由：

```text
PostgreSQL
→ conversations / messages / request_runs

Redis Stream
→ 运行中事件流（run:123:events）
```

承担。不要自己建 checkpoint ORM / 持久化层。

先在普通 Chat 上验证：

```text
会话持久化
restart
resume
multi-instance
delete
```

再让复杂 Travel Agent 使用它。

# 10. Idempotency

至少：

```text
(user_id, idempotency_key)
```

running duplicate：

```text
返回现有 request
```

completed duplicate：

```text
返回现有结果
```

不得重复 Agent cost。

---

# 11. Deadline / Cancellation

Request Deadline 是 End-to-End。

LiteLLM timeout 只是单次模型调用 timeout。

Streaming stop 必须尽可能传播：

```text
frontend
→ FastAPI
→ Agent
→ model/tool
```
