# 5. Business Durability / Stream Resume / Execution Durability

必须三分：

```text
PostgreSQL
→ Conversation / Message / RequestRun

StreamResumeStore
→ active stream reconnect only

DBOS / Temporal future
→ process crash / restart execution resume
```

当前 `RedisStreamResumeStore`：

```text
Redis KV state
+ Redis Pub/Sub
+ producer-memory backlog
```

不使用 Redis Streams 作为默认 per-chunk durable log。

# 9. Disconnect / Stop

Disconnect：

```text
F5 / network disconnect
→ detach subscriber
→ execution continues
```

当前代码里 disconnect 会取消 execute task，这是 M8 transitional debt。

Product Stop：

```text
POST cancel
→ RequestRun CAS
→ Product cancellation signal
→ PydanticAI first-party cancellation
```

不要用：

```text
useChat.stop()
fetch abort
subscriber disconnect
```

替代 Product Stop。
