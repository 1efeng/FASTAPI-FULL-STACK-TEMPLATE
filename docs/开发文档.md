```text

```

# 8. LangGraph Persistence

使用：

```text
AsyncPostgresSaver
```

不要自己建 checkpoint ORM。

先在普通 Chat 上验证：

```text
thread persistence
restart
resume
multi-instance
delete
```

再让复杂 Travel Agent 使用它。

# 10. Idempotency

至少：

```text
(user_id, idempotency_key)
```

running duplicate：

```text
返回现有 request
```

completed duplicate：

```text
返回现有结果
```

不得重复 Agent cost。

---

# 11. Deadline / Cancellation

Request Deadline 是 End-to-End。

LiteLLM timeout 只是单次模型调用 timeout。

Streaming stop 必须尽可能传播：

```text
frontend
→ FastAPI
→ Agent
→ model/tool
```
