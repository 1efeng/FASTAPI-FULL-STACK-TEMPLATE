# 配置契约

> 更新时间：2026-08-13
> 状态：v8 clean baseline

# 1. 原则

- 配置集中；
- Secret 不进 Git；
- production 启动时 fail-fast 校验关键配置；
- 版本、环境、Provider 不通过散落 if/else 管理；
- 当前真实配置以代码 Settings + env + `uv.lock` 为准。

# 2. Environment

```text
development
test
production
```

test 必须可使用 fake provider / deterministic fixtures。

# 3. Application

建议分组：

```text
APP_ENV

DATABASE_URL
REDIS_URL

REQUEST_DEADLINE_SECONDS

OTEL_*

LITELLM_BASE_URL
LITELLM_SERVICE_KEY
LLM_LOGICAL_MODEL

MODEL_CALL_LIMIT
TOOL_CALL_LIMIT
```

具体字段以实现 Contract 为准。

# 4. LiteLLM

Provider secrets 属于 LiteLLM，不属于 Travel Agent app：

```text
DEEPSEEK_API_KEY
FALLBACK_PROVIDER_API_KEY
LITELLM_MASTER_KEY
LITELLM_DATABASE_URL
LITELLM_REDIS_*
```

LiteLLM config file / secret store 管 model groups、fallback 等。

# 5. PostgreSQL

业务（Travel Agent）与 LiteLLM 可以使用不同 logical DB/user：

```text
TRAVEL_AGENT_DATABASE_URL
LITELLM_DATABASE_URL
```

第一阶段可以指向同一 server。

> 历史说明：M5 LangGraph Persistence 已 SUPERSEDED，v8 clean baseline 不再维护独立的 LangGraph DB；durability 由 PostgreSQL / Redis Stream 承担（DBOS 后续引入）。

# 6. Redis

可以共享 server，但 namespace / key prefix 分开。

M6 Chat Business Protection：

```text
CHAT_IP_RATE_LIMIT_PER_MINUTE
→ 单个来源 IP 的每分钟请求上限

CHAT_USER_RATE_LIMIT_PER_MINUTE
→ 单个用户的每分钟请求上限

CHAT_DAILY_QUOTA
→ 单个用户每日可执行请求数

CHAT_CONCURRENT_LIMIT
→ 单个用户同时运行的请求数

CHAT_REDIS_FAILURE_POLICY
→ fail_closed 默认保护模型成本；fail_open 仅用于明确接受降级风险的环境
```

# 7. Security

```text
JWT / SESSION secrets
CORS origins
retention
PII policy
trace payload policy
```

不得使用弱默认 Secret 在 production 启动。

# 8. Version Source of Truth

Python：

```text
pyproject.toml → compatible dependency declaration
uv.lock        → exact tested dependency set
```

Production build 使用 locked/frozen sync。

LiteLLM：

```text
container image tag/digest → exact tested gateway version
```

# 9. Version-dependent Capability

下列能力使用前必须验证 locked version：

- FastAPI Agent Streaming Adapter / locked official protocol；
- AgentExecutor（v8 clean baseline 暂无实现，Pydantic AI 下一里程碑接入）；
- LiteLLM config schema。

# 10. Secret Rotation

Secret rotation 不能要求重新构建镜像；通过 deployment secret mechanism 更新。

# 11. 禁止

```text
API_KEY hardcoded in source
production default password
provider keys copied into multiple services
unversioned production image
```
