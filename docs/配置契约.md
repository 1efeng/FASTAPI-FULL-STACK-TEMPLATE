# Travel Agent v8.2 配置契约

> 更新时间：2026-08-13  
> 原则：当前真实字段以 Settings / env / lockfile 为准；未实现 target 配置不得提前假装存在。

# 1. 基本原则

```text
配置集中
Secret 不进 Git
production fail-fast
exact tested dependency versions locked
Product / Agent / Gateway ownership 分离
```

# 2. Application

当前/长期核心：

```text
APP_ENV
APP_TIMEZONE
DATABASE_URL
REDIS_URL
REQUEST_DEADLINE_SECONDS
TRAVEL_RESEARCHER_TIMEOUT_SECONDS
LITELLM_CLIENT_TIMEOUT_SECONDS

CHAT_IP_RATE_LIMIT_PER_MINUTE
CHAT_USER_RATE_LIMIT_PER_MINUTE
CHAT_DAILY_QUOTA
CHAT_CONCURRENT_LIMIT
CHAT_REDIS_FAILURE_POLICY

LITELLM_BASE_URL
LITELLM_SERVICE_KEY
LLM_LOGICAL_MODEL
```

具体字段必须以当前代码 `app/core/config.py` 为准。

# 3. Redis Ownership

单个 app Redis client 由：

```text
app.infra.redis
```

统一拥有。

`RedisStreamResumeStore`：

```text
注入现有 Redis client
store.close() 只关闭自己的 Pub/Sub / producer task
不得关闭共享 Redis client
```

# 4. Stream Resume Target Settings

当前实现存在 constructor defaults；M8 wiring 后如需要配置化，建议统一到 Product Settings：

```text
STREAM_RESUME_KEY_PREFIX
STREAM_RESUME_TTL_SECONDS
STREAM_RESUME_ACK_TIMEOUT_SECONDS
STREAM_RESUME_HEARTBEAT_SECONDS
```

在 Settings 真正落地前：

```text
不要在 env.example 宣称已支持
不要在 Product module 重复定义
```

# 5. Stream Identity

配置不允许改变 Product identity：

```text
stream_id = str(request_id)
```

不提供：

```text
STREAM_ID_MODE
REDIS_STREAM_CURSOR_MODE
```

之类业务配置。

# 6. LiteLLM

Provider secret 归 LiteLLM：

```text
provider API keys
LITELLM_MASTER_KEY
LITELLM_DATABASE_URL
LiteLLM Redis/config
```

Travel Agent app 只持有 gateway service credential / logical model。

# 7. PydanticAI / AI SDK Version Gate

M8 必须锁定：

```text
PydanticAI exact tested version
ai exact tested major/version
@ai-sdk/react exact tested version
VercelAIAdapter explicit sdk_version
```

compatibility test 通过后再升级。

# 8. PostgreSQL

```text
Business DB
LiteLLM DB/schema
```

migration ownership 分离。

Active Stream Resume 不增加第三个 PostgreSQL durability domain。

# 9. Execution Durability

M8 没有 DBOS 配置。

只有引入 gate 通过后才新增：

```text
DBOS_*
TEMPORAL_*
```

不能因为 StreamResumeStore 已存在就声称 execution durable。

# 10. Security

```text
JWT/session secrets
CORS origins
TLS
retention
PII policy
trace payload policy
```

production 禁止弱默认 Secret。

# 11. 禁止

```text
API key hardcoded
Product app 保存 provider root keys
多个 Redis client 各自 lifecycle
stream_resume 自己读取 REDIS_URL 再建第二连接池
unversioned AI SDK/Pydantic compatibility
把 Redis Streams event id 配成 Product cursor contract
```
