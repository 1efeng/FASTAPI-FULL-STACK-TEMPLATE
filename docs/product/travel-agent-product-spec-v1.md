# Travel Agent 产品规格文档 v1

## 1. 产品定位

Travel Agent 不是一个搜索旅游信息的机器人，而是一个旅行决策系统。

核心价值：

> 理解用户为什么旅行，并帮助用户做出符合目标、约束和现实条件的旅行决策。

用户购买的不是景点列表，而是一段合适的旅行体验。

---

## 2. 用户真实需求模型

旅行规划必须理解：

- 旅行目的
- 同行关系
- 体验目标
- 节奏偏好
- 预算约束
- 不可接受事项

示例：

情侣：
- 创造共同记忆
- 拍照
- 浪漫体验
- 舒适节奏

亲子：
- 安全
- 趣味
- 少等待

父母：
- 舒适
- 少步行
- 风险低

---

## 3. 用户输入模型

基础信息：

- 目的地
- 出发地
- 日期
- 人数
- 预算

增强信息：

- 旅行关系
- 旅行目的
- 偏好体验
- 节奏要求
- 住宿偏好
- 饮食偏好
- 禁忌事项

---

## 4. LLM能力边界

实验结论：

DeepSeek V4 Flash 无联网已经能够：

- 理解需求
- 生成路线
- 粗预算
- 安排节奏

不足：

- 动态事实不可靠
- 缺少现实验证
- 不知道哪些信息影响决策

因此系统重点不是增加搜索，而是管理决策信息。
