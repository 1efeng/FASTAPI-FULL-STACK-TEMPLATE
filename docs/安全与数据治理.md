# 安全与数据治理

# 1. Authentication / Authorization

AuthN = 你是谁。  
AuthZ = 资源是不是你的。

所有 conversation / request 访问必须 scope 到 current user。

客户端传入的：

```text
user_id
conversation_id
request_id
thread_id
checkpoint_id
```

都不是天然可信授权依据。

# 2. LiteLLM Access

C-End 用户不直接访问 LiteLLM。

```text
C-End User
→ FastAPI Auth
→ Travel Agent
→ LiteLLM Service Key
```

Provider keys 只存在 LiteLLM / secret system。

# 3. PII

Agent pipeline 的 PII 防护优先复用基础设施成熟能力（如 OTel redaction、LiteLLM hooks、DB 层脱敏）。

PII 防护还必须覆盖：

- API logs；
- OTel；
- LiteLLM logs；
- DB；
- backup；
- support tools。

# 4. Secret

禁止进入：

- Prompt；
- Tool result；
- ordinary logs；
- LiteLLM request metadata；
- error message。

# 5. External Research

网页 / 搜索结果全部是 untrusted data：

```text
External Content
≠ System Instruction
≠ Developer Instruction
```

不得因为网页说“忽略规则”就改变 Agent policy。

# 6. SSRF

如果未来加入 arbitrary URL fetch：

- allowlist / safe resolver；
- 禁止 metadata/internal network；
- redirect validation；
- size/time limit。

当前 Search result URL 不自动等价于任意 fetch 权限。

# 7. Input Limits

P0：

- body size；
- message length；
- file/attachment policy（未来）；
- rate；
- concurrency。

# 8. Observability Data Policy

必须明确：

- 是否保存完整 prompt；
- 是否保存完整 response；
- 是否采样；
- 保存多久；
- 是否脱敏；
- 哪些 workspace/member 可访问。

默认最小必要采集。

# 9. Provider Data Boundary

文档化：

- 哪些消息发送给 LLM provider；
- 哪些 metadata 发送 LiteLLM；
- 哪些 Tool result 会进入模型；
- Provider retention / training policy 由实际合同/产品配置确认。

# 10. Retention / Delete

至少定义：

```text
conversation retention
trace retention
usage retention
backup retention
delete propagation
```

用户删除不能只隐藏 UI。

# 11. Abuse

层次：

```text
IP rate limit
user rate limit
AI daily quota
concurrent limit
input-size limit
LiteLLM service-level RPM/TPM
```

Business quota 与 LiteLLM infrastructure limit 不互相替代。

# 12. Transport

- HTTPS；
- secure headers；
- explicit CORS；
- auth cookie 时配置安全属性；
- 不通过 query string 传 Secret。

# 13. Admin / Support

支持人员访问用户 conversation 必须：

- 明确授权；
- audit；
- 最小权限；
- 有合理业务目的。

# 14. Release Gate

上线前至少验证：

- IDOR / ownership；
- secret leakage；
- prompt injection；
- PII logging；
- rate/quota bypass；
- deletion path；
- CORS/auth configuration。
