# 5. Step 2 — AgentExecutor Contract 硬化（server-authoritative history）

**进度：🚧 未开始（当前施工位）**

当前事实（已核对代码）：

```text
executor.py 54 行，仍是 thin execute(request_id, conversation_id, message, deadline_at)
无 AgentMessage / AgentExecutionRequest / history 字段
get_agent_executor() 抛 AgentRuntimeNotConfigured
```

## 目标

把 thin `execute(...)` 升级为携带服务端权威历史的请求 DTO。这是 Step 3（PydanticAI 接入）的前置，避免 Agent 反向查 Product DB 补上下文。

## 输出

```text
backend/app/agent/executor.py   ← 新增 AgentMessage / AgentExecutionRequest，改造 Protocol
backend/app/modules/chat/service.py  ← 新增 history projection
backend/tests/*                 ← FakeExecutor 覆盖新契约
```

目标 contract（架构 SOT 5.3 节）：

```python
@dataclass(frozen=True, slots=True)
class AgentMessage:
    role: Literal["user", "assistant"]
    content: str

@dataclass(frozen=True, slots=True)
class AgentExecutionRequest:
    request_id: UUID
    conversation_id: UUID
    message: str
    history: tuple[AgentMessage, ...]   # 服务端权威历史
    deadline_at: datetime

@dataclass(frozen=True, slots=True)
class AgentExecutionResult:
    content: str

class AgentExecutor(Protocol):
    async def execute(self, request: AgentExecutionRequest) -> AgentExecutionResult: ...
```

## 权威流向（不可逆）

```text
PostgreSQL durable Messages
  → ChatService history projection
  → AgentExecutionRequest.history
  → AgentExecutor.execute
```

## 验收 checklist（Definition of Done）

```text
🚧 ChatService 从 Product DB 投影 user/assistant 历史，组装 history
🚧 history 顺序稳定（按 Message.seq 升序）
🚧 history 不含 tool scratchpad / private reasoning / system prompt
🚧 FakeExecutor 能断言收到完整 history
🚧 幂等 replay 时 history 不重复投影
🚧 多轮对话：第二轮 history 含第一轮 user + assistant
🚧 framework-neutral Product tests 全绿（ruff / mypy / ty / pytest）
```

## 禁止

```text
❌ PydanticAIExecutor 反向 import ConversationRepository
❌ history 接受浏览器 UIMessage 作为真实来源
❌ 把 streaming partial chunk 写进 history
❌ 本次同时接 PydanticAI（保持 Step 2 纯 Product 契约变更）
```

# 10. Step 6 — Lifecycle-aware Streaming + Terminal Gate

**进度：⏸ 未开始（Gate A 后）**

## 目标

## 输出

```text
backend/app/modules/chat/streaming.py  ← VercelAIAdapter + Terminal Gate + Store wiring
```

主链路：

```text
PydanticAI events → VercelAIAdapter → Terminal Gate → StreamResumeStore → subscriber
```

## Terminal Gate 硬规则

```text
非 terminal（text/tool/source/data/metadata）→ 可实时发布
Agent finish candidate → HOLD
  → Product Success TX（assistant INSERT + RequestRun completed CAS + COMMIT）
  → RELEASE finish terminal chunk
```

## 验收 checklist（Definition of Done）

```text
🚧 non-terminal chunk 可早于 Product COMMIT（断言）
🚧 success terminal event 绝不早于 Product COMMIT（断言）
🚧 Product COMMIT 成功后 terminal emit 失败 → Product 保持 completed，不回滚
🚧 failed/cancelled partial output 不写 Product Message
🚧 StreamResumeStore 拿到的是 opaque string（不解析协议）
🚧 D3 债务清除：StreamResumeStore 接入 Chat streaming path
```
