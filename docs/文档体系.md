# Travel Agent 文档体系

本目录是全程 Vibe Coding 的 Source of Truth。

## 1. 文档层级

```text
AGENTS.md
  ↓ Coding 宪法
docs/文档体系.md
  ↓ 文档 Owner / 冲突规则
核心文档
  ├── 产品文档.md      WHAT / WHY
  ├── 架构v7.md        SYSTEM / OWNER
  ├── 开发文档.md      HOW TO BUILD
  └── 路线图.md       WHAT NEXT
        ↓
Implementation Contracts
        ↓
ADR
```

## 2. 冲突优先级

发生冲突时：

1. 当前代码事实用于判断“已实现什么”；
2. `AGENTS.md` 决定 Coding 硬规则；
3. `架构v7.md` 决定系统 Owner / 边界；
4. 对应 Contract 决定接口或实现契约；
5. `产品文档.md` 决定产品行为；
6. `路线图.md` 只决定进度与优先级；
7. ADR 解释为什么做出重大决策，不覆盖更新后的架构正文；
8. `IMPLEMENTATION_NOTES.md` 仅是当前实现快照。

发现冲突必须修正文档，不得让冲突长期存在。

## 6. 不允许出现的文档模式

禁止为同一 Owner 再创建多个并行 Source of Truth，例如：

```text
AUTH_DESIGN.md + SECURITY_V2.md + NEW_SECURITY.md
GATEWAY_NOTES.md + LLM_GATEWAY_V2.md
DATABASE_NEW.md + DB_FINAL.md
```

重大决策使用 ADR；当前 Contract 直接更新为唯一最新版。
