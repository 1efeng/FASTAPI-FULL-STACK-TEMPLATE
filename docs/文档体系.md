# 3. 冲突优先级

1. 当前真实代码决定“现在已经实现什么”。
2. `AGENTS.md` 决定 Codex/Agent 施工硬规则。
3. `docs/架构v8.md` 决定 Architecture ownership / target。
4. 对应专项 Contract 决定 domain contract。
5. `docs/施工路线图.md` 决定施工顺序。
6. 产品文档决定产品行为意图。
7. 历史文档 / superseded 文档只能做研究参考。

如果 CURRENT 与 TARGET 不同：

```text
代码 = CURRENT
架构v8.md = TARGET
施工路线图 = 从 CURRENT 到 TARGET 的顺序
```

禁止为了让文档“看起来一致”而把未实现 target 标成已完成。
