
# 4. 当前接口

当前已有：

```text
POST /api/v1/chat
GET  /api/v1/chat/requests/{request_id}
POST /api/v1/chat/requests/{request_id}/cancel
```

定位：

```text
authenticated integration endpoint
non-streaming
FastAPI → ChatService → Business Start Transaction → AgentExecutor → Business Final Transaction
```

当前请求必须携带：

```http
Idempotency-Key: <non-blank, max 255>
```

```json
{
  "conversation_id": "<owned active conversation UUID>",
  "message": "<non-empty text>"
}
```

服务端生成的 `request_id` 同时作为 `request_run.id`。调用 Agent 前完成：

```text
owned active conversation check
+ request_run(running)
+ user message
+ conversation.last_message_at
+ COMMIT
```

Agent 成功后原子提交 assistant final 与 `request_run(completed)`；失败和任务取消通过条件更新写入 `failed/cancelled`。客户端可以按当前用户 ownership 查询 durable request status，越权与不存在统一返回 404。

```http
GET /api/v1/chat/requests/{request_id}
```

Product API 不暴露 Agent Runtime 内部 session 标识；Business Conversation 与 Agent Runtime session 解耦。

当前同步接口已经实现：

```text
(user_id, idempotency_key) 数据库幂等
running duplicate → 202 + existing request
completed duplicate → 200 + durable assistant final
payload mismatch → 409 DUPLICATE_REQUEST
IP/user rate + daily quota + user concurrency
absolute deadline + remaining time
owned explicit cancel
```

显式取消接口：

```http
POST /api/v1/chat/requests/{request_id}/cancel
```

越权与不存在统一返回 404；已进入终态的请求重复取消会返回当前终态。当前非流式 Chat 在 HTTP 断线后继续 durable run，客户端使用 status API 恢复、使用 cancel API 主动停止。M8 Streaming Spike 再验证 stream disconnect 的取消传播。

当前仍未完成 Streaming 与 Business Usage Attribution。

# 6. Streaming / Chat Runtime（M8 决策）

P0 不冻结一套独立自研的 Agent wire protocol，也不把 `status/message_delta/heartbeat/final/error` 作为长期协议 SOT。

M8 Streaming Spike 负责决策：

```text
后端：流式协议形态与 FastAPI Agent Streaming Adapter 的 endpoint shape
前端：Chat Runtime 实现（候选：Vercel AI SDK / @ai-sdk/react）
```

具体 endpoint shape 在 M8 Spike 后冻结。不要根据文档示例 URL 提前永久锁定（如 `/threads/*`、`/runs/*`），必须通过当前 locked version Contract Test。

FastAPI 负责：

```text
HTTP/SSE
Auth
Lifecycle
Cancellation
Business durability
```

候选 Stream Surface（M8 决策项，暂不冻结）：

```text
Phase A：message submit / assistant stream / completion / error / cancel / thread state / rejoin/reconnect（可用时）
Phase B（Travel Gate 后）：Research status / Tool lifecycle projection / SubAgent projection / Sources / Travel custom state
```

# 7. Durable Final

完成条件：

```text
assistant message durable
+
request_run completed
+
COMMIT
```

stream 丢失不影响 durable result。

# 8. Conversation / Runtime Session

Business Conversation 与 Agent Runtime session 解耦，任何 client id 都不能替代 ownership check。

# 9. Error

客户端只消费 Product Error Code，不泄漏 provider / runtime / DB internals。
