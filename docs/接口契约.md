
# 2. Authentication

```http
Authorization: Bearer <token>
```

所有 Conversation / RequestRun / Stream / Cancel 必须按 current user ownership 校验。

---

# 3. Idempotency

昂贵 Agent 请求：

```http
Idempotency-Key: <client-generated-key>
```

作用域：

```text
(current_user.id, idempotency_key)
```

网络 retry 复用相同 key；新业务发送使用新 key。

---

# 4. 当前已实现接口

```text
POST /api/v1/chat
GET  /api/v1/chat/requests/{request_id}
POST /api/v1/chat/requests/{request_id}/cancel
```

当前 `POST /chat` 为 authenticated non-streaming integration endpoint。

请求：

```json
{
  "conversation_id": "<owned active conversation UUID>",
  "message": "<non-empty text>"
}
```

服务端生成：

```text
request_id == request_run.id
```

Agent 执行前：

```text
owned active conversation check
+ request_run(running)
+ durable user message
+ conversation.last_message_at
+ COMMIT
```

成功：

```text
assistant final
+ request_run completed
+ COMMIT
```

失败/取消通过 `running → terminal` conditional update。

---

# 5. Request Status

```http
GET /api/v1/chat/requests/{request_id}
```

职责：

```text
durable Product RequestRun status
durable error_code
ownership check
reconciliation source
```

Transport/stream 状态不得替代该接口。

---

# 6. Product Cancel

```http
POST /api/v1/chat/requests/{request_id}/cancel
```

语义：

```text
ownership check
→ RequestRun running → cancelled CAS
→ Product cancellation signal
→ Agent first-party cancellation
```

`cancelled` 表示：

> Product cancellation 赢得 terminal race；任何 late Agent final 均不得再作为 Product final commit。

它不保证底层 coroutine 在完全相同的瞬间物理退出。

越权和不存在统一按当前 Product security contract 返回。

---

# 7. M8 Target：Product Start / Stream 两平面

Production streaming 不允许让 Pydantic `dispatch_request()` 绕过 Product lifecycle。

目标逻辑：

```text
POST Product Chat/Start
→ Auth/AuthZ
→ Admission
→ Idempotency
→ Product Start TX
→ request_id
→ ExecutionSupervisor starts execution
```

然后：

```text
GET /api/v1/chat/requests/{request_id}/stream
→ attach active UI stream
```

最终精确 endpoint path 在 M8 implementation contract test 后冻结，但必须满足：

```text
request_id 是唯一 Product/stream identity
无需 browser 持有 Redis key
无需 browser 持有 Redis Stream ID
```

# 8. Active Stream Resume

Backend owner：

```text
StreamResumeStore
```

Current implementation：

```text
RedisStreamResumeStore
```

reconnect：

```text
GET stream endpoint
→ owned RequestRun check
→ store.resume(str(request_id))
```

返回语义建议：

```text
200 → active stream available
204 → no active stream; client must reconcile Product status/history
404 → resource not owned / unavailable according to Product security contract
```

第一版默认：

```text
skip_characters = 0
```

不把 cursor 固定为 Product API contract。

---

# 9. Streaming Protocol

Browser stream protocol：

```text
Vercel AI SDK UI protocol
```

Producer：

```text
PydanticAI events
→ VercelAIAdapter
→ encoded SSE chunks
```

`StreamResumeStore` 把 chunk 当 opaque string，不解析协议。

不维护第二套：

```text
run.started
text.delta
tool.started
...
```

自研 browser wire protocol。

---

# 10. Terminal Event Ordering

Product completed 条件：

```text
assistant final durable
+
RequestRun completed
+
PostgreSQL COMMIT
```

只有之后才允许：

```text
success finish terminal UI event
```

如果 Product COMMIT 成功但 transport terminal emit 失败：

```text
Product 状态保持 completed
→ 不回滚
→ client 用 status/history reconcile
```

---

# 11. Disconnect

目标 M8：

```text
HTTP/SSE disconnect
→ detach subscriber only
→ Product Request remains running
→ execution continues
```

当前 `ChatService` disconnect watcher 会取消 execute task，这是 transitional debt，不是最终 Contract。

---

# 12. Partial Output

```text
completed
→ durable assistant final

failed / cancelled
→ partial stream output 不写 Business Message
```

Stream retention 到期后，durable history 不显示失败/取消 run 的 partial assistant。

---

# 13. Error

客户端只消费 Product Error Code。

Provider / Pydantic / Redis / DB raw exception 不直接透传。

Transport resume 失败不应伪造 Product `failed`；优先：

```text
transport error
→ GET RequestRun
→ durable reconciliation
```

---

# 14. Client History

Browser `messages` 不是 trusted Product history。

Agent history：

```text
PostgreSQL Product Message
→ Product Runtime projection
→ AgentExecutionRequest.history
```

客户端不得伪造 tool approval/tool calls/system history 成为 server authoritative state。
