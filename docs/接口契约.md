# 4. 当前接口

当前已有：

```text
POST /api/v1/chat
GET  /api/v1/chat/requests/{request_id}
```

定位：

```text
authenticated integration endpoint
non-streaming
FastAPI → ChatService → Business Start Transaction → Agent/LangGraph → Business Final Transaction
```

当前请求必须携带：

```http
Idempotency-Key: <non-blank, max 255>
```

```json
{
  "conversation_id": "<owned active conversation UUID>",
  "message": "<non-empty text>"
}
```

服务端生成的 `request_id` 同时作为 `request_run.id`。调用 Agent 前完成：

```text
owned active conversation check
+ request_run(running)
+ user message
+ conversation.last_message_at
+ COMMIT
```

Agent 成功后原子提交 assistant final 与 `request_run(completed)`；失败和任务取消通过条件更新写入 `failed/cancelled`。客户端可以按当前用户 ownership 查询 durable request status，越权与不存在统一返回 404。

```http
GET /api/v1/chat/requests/{request_id}
```

Product API 不暴露 LangGraph thread id。服务端使用 Conversation 的独立 `langgraph_thread_id` 作为 checkpoint `thread_id`。

当前仍不是最终 Production Chat Contract：幂等重放、业务 rate/quota/concurrency、显式取消与 streaming 尚未完成。

# 6. Streaming

P0 不冻结一套独立自研的 Agent wire protocol，也不把 `status/message_delta/heartbeat/final/error` 作为长期协议 SOT。

M8 Streaming Spike 负责验证当前锁定版本的 LangChain/LangGraph Agent Streaming Protocol，由 FastAPI Agent Streaming Adapter 接入 Product Lifecycle，再由 `@langchain/react` 消费。

FastAPI 负责：

```text
HTTP/SSE
Auth
Lifecycle
Cancellation
Business durability
```

# 7. FastAPI Agent Streaming Adapter

具体 endpoint shape 在 M8 Spike 后冻结。

```text

```

# 10. Durable Final

完成条件：

```text
assistant message durable
+
request_run completed
+
COMMIT
```

stream 丢失不影响 durable result。

# 11. Conversation / Thread

```text
Business Conversation
!=
LangGraph Thread
```

任何 client id 都不能替代 ownership check。

# 12. Error

客户端只消费 Product Error Code，不泄漏 provider / graph / DB internals。
