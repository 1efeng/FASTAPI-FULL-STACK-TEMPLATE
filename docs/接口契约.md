# 接口契约

> P0 API 保持少而稳定。  
> Transport Owner：FastAPI。  
> SSE 优先使用项目锁定版本支持的 FastAPI Native SSE。

# 1. Base

```text
/api/v1
```

JSON 使用 UTF-8。

# 2. Authentication

```http
Authorization: Bearer <token>
```

具体 Auth Provider 不在本 Contract 锁死。

# 3. Idempotency

昂贵写/执行请求：

```http
Idempotency-Key: <client-generated-key>
```

作用域至少：

```text
(current_user.id, idempotency_key)
```

# 4. Identity

每次请求建立：

```text
request_id  → business identity
trace_id    → OpenTelemetry trace identity
```

客户端可以拿 `request_id` 查询状态；不应该自行指定可信 `trace_id`。

# 5. POST /api/v1/chat/stream

示例：

```json
{
  "conversation_id": "optional-existing-id",
  "message": "2026年8月东京进大阪出，帮我规划5天"
}
```

服务器：

1. AuthN / AuthZ；
2. rate/quota/concurrency；
3. idempotency；
4. persist request + user message；
5. Agent；
6. persist final；
7. SSE final。

# 6. SSE Event Contract

## status

```json
{
  "request_id": "...",
  "stage": "research",
  "message": "正在查询最新旅行信息…"
}
```

## message_delta

可选。用于未来逐步展示最终文本，不承诺 Chain of Thought。

## heartbeat

Transport keepalive；不表达业务进度。

## final

```json
{
  "request_id": "...",
  "conversation_id": "...",
  "message_id": "...",
  "content": "..."
}
```

发送前 Business Final 必须 durable。

## error

```json
{
  "request_id": "...",
  "code": "MODEL_UNAVAILABLE",
  "message": "当前规划服务暂时繁忙，请稍后重试。",
  "retryable": true
}
```

# 7. POST /api/v1/chat

当前已实现受 Bearer Auth 保护的同步 Agent 接口：

```json
{
  "message": "请帮我规划上海两日游"
}
```

成功响应：

```json
{
  "request_id": "server-generated-uuid",
  "content": "..."
}
```

该接口当前完成 `FastAPI → Deep Agents → LiteLLM → Provider` 的真实调用，并应用请求 deadline 与 recursion limit。Conversation、Message、RequestRun、幂等和 durable final 尚未接入；在这些能力完成前，不能把同步响应视为可恢复的业务记录。

# 8. GET /api/v1/conversations

只返回当前用户资源。

# 9. GET /api/v1/conversations/{conversation_id}

必须校验 ownership。

# 10. DELETE /api/v1/conversations/{conversation_id}

触发业务删除与关联 LangGraph state 清理策略。

# 11. GET /api/v1/requests/{request_id}

返回：

```text
running
completed
failed
cancelled
```

如果 completed，可返回或定位 final result。

# 12. Duplicate Behavior

```text
同 user + same key

running
→ 返回已有 request identity/status

completed
→ 返回已有 completed result/status

不得重新启动 Agent
```

# 13. Cancellation

客户端断开或显式取消时：

- 尝试取消 downstream model / tools；
- 标记 request 状态；
- 已经 durable completed 的结果不能因断线改为失败。

# 14. Deadline

Request Lifecycle 创建绝对 End-to-End Deadline。

超时：

```text
REQUEST_DEADLINE_EXCEEDED
```

LiteLLM timeout / Tool timeout 只是 downstream timeout。

# 15. Health

```text
GET /health/live
GET /health/ready
```

readiness 应考虑应用依赖的关键基础设施，但不要把短暂非关键 Tool failure 全部映射为进程不 ready。

# 16. Native SSE Version Gate

使用 `fastapi.sse` 前：

- 检查实际 locked FastAPI 版本；
- 若版本不满足，先升级并测试；
- 不为了兼容旧版本长期维护自研 SSE Framework。

# 17. Compatibility

P0 API breaking change 必须显式版本化或同步 Client，不允许静默改字段。
