# 6. Streaming

P0 不冻结一套独立自研的 Agent wire protocol，也不把 `status/message_delta/heartbeat/final/error` 作为长期协议 SOT。

M8 Streaming Spike 负责验证当前锁定版本的 LangChain/LangGraph Agent Streaming Protocol，由 FastAPI Agent Streaming Adapter 接入 Product Lifecycle，再由 `@langchain/react` 消费。

FastAPI 负责：

```text
HTTP/SSE
Auth
Lifecycle
Cancellation
Business durability
```

# 7. FastAPI Agent Streaming Adapter

具体 endpoint shape 在 M8 Spike 后冻结。

不要根据文档示例 URL 提前永久锁定：

```text
/threads/*
/runs/*
```

必须通过当前 locked version Contract Test。

# 10. Durable Final

完成条件：

```text
assistant message durable
+
request_run completed
+
COMMIT
```

stream 丢失不影响 durable result。

# 11. Conversation / Thread

```text
Business Conversation
!=
LangGraph Thread
```

任何 client id 都不能替代 ownership check。

# 12. Error

客户端只消费 Product Error Code，不泄漏 provider / graph / DB internals。
